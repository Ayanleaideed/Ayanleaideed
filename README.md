**FeedbackControl.java**

An encoder-angle conversion and a proportional-control calculation. The latter is the P term only, not a full PID controller.

```java
final class FeedbackControl {
    static double angleRadians(
            long ticks, int ticksPerTurn) {
        if (ticksPerTurn <= 0)
            throw new IllegalArgumentException();
        return ticks * (2.0 * Math.PI / ticksPerTurn);
    }

    static double proportional(
            double target, double measured,
            double gain) {
        return gain * (target - measured);
    }
}
```
